ZORATracker, web version

This is the same tracker as the desktop app, with what a web page can't do turned off:
  • global hotkeys (keys work only while this page has focus), gamepad and voice commands
  • pop-out windows: HUDs, the broadcast window and other separate windows
  • auto-update and fake clicks or mouse movement
Settings and the autosave are kept in this browser. Other saves are also downloaded; open them with Load Save on the start screen. For everything else, get the desktop app.

ZORATracker is open in another tab

Both tabs save to the same autosave. The other tab has stopped saving, so this tab's progress is kept; close the other tab.
