## Install

1. Download the latest zip from the [Releases page](https://github.com/TheGobOne/ZoraTracker/releases/latest).
2. Unzip it into a folder you want to keep. Your settings, hotkeys and saves live beside the program.
3. Run `Z1R_WPF.exe`.

Windows may warn about an unknown app the first time. Choose **More info**, then **Run anyway**. If your antivirus quarantines `Z1R_WPF.exe`, restore it from the quarantine list.

## Your first run

1. On the [start screen](start-screen.md), click **Paste Flags**, paste the Z1R and ZORA flag strings from the ZORA site, and click **Apply**.
2. Check the startup options your seed uses (Item Shuffle, Mirrored Overworld, and so on).
3. Click the overworld your seed uses (**1st Quest**, **2nd Quest**, **Mixed** or **Randomized**). The tracker starts.
4. Mark things as you find them. Click a map tile, an item box or a dungeon room to open its menu.

Click **Guided Tour** on the start screen at any time for a walkthrough of both screens.

## Saving and loading

- **Save** (top right of the main screen) writes a save file.
- **Load Save** on the start screen resumes any save file. The three most recent saves are listed under **Recently loaded saves**.
- **Auto-save** runs on its own. Set the interval in [Options](options.md).
- A loaded save restores its own Item Shuffle, Hide Dungeon Numbers and overworld settings, so the start screen choices are ignored.

## Updating

The tracker checks for new releases. The version button at the bottom of the start screen shows what is new, and glows when an update is available. You can also grab the newest zip from the [Releases page](https://github.com/TheGobOne/ZoraTracker/releases/latest).

## When something breaks

**Options → Show Crash Log...** opens the crash log. Attach it when you [open an issue](https://github.com/TheGobOne/ZoraTracker/issues).
