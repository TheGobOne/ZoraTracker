# ZORATracker 3.3 release notes

Compared against the 3.2 release. Published 2026-11-27.

## Discord copy

**ZORATracker 3.3**

**New**
- Map, Compass and Triforce shuffle window (Popout Windows > M/C/Tri Shuffle): place maps, compasses and triforces in dungeon boxes, or in Overworld spots under Shuffle Anywhere. This is a rough 1st iteration. It's not elegant but it gets something in your hands to be able to track shuffle. Feedback is welcome!

Thanks to everyone for the bug reports and feedback.
