### GitHub release: ZORATracker 2.2.0-beta-22-hotfix1 (latest)

**Fixes (cross-platform port)**
- Fixed a crash when marking a spot (for example pressing 8 for the white sword cave) while the pointer was over an item box that got redrawn.
- The whistle order tip no longer covers the recorder spot, and it no longer shows on 1st Quest.
- Moving a tile menu with Shift held no longer jumps to the red X or re-picks "clear this tile", and the first click now works.
